Is the data in long or wide format? How can you tell?

plotting

Create a plot to look at how many projects were entered each semester by each department.

(ggplot(df_long, aes(x="Semester_Date", y="Count", color="Department")) + geom_line())

Do you see any issues with the plot? What do you think is causing the problem?

Fix the issue and try plotting again.

df_filled = df_long.with_columns(pl.col("Count").fill_null(0))
(ggplot(df_filled, aes(x="Semester_Date", y="Count", color="Department")) + geom_line())

It’s a bit busy, maybe we can break it out into small multiples. In other words a different plot for each Department.

departments = df_filled["Department"].unique()
for department in departments:
    df_department = df_filled.filter(pl.col("Department") == department)
    (
        ggplot(df_department, aes(x="Semester_Date", y="Count"))
        + geom_line()
        + labs(x="Semester Start Date", title=department)
    ).show()
